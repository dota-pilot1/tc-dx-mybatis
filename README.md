# TC Toolkit for Commerce

커머스 서비스를 설계하고 구현하기 위한 Towercrane 기반 Tauri 데스크톱 툴킷입니다.

## 목적

커머스 개발은 코드보다 먼저 정리해야 할 도메인 지식과 정책이 많습니다. 이 앱은 자사몰, 입점형 커머스, 도매몰 연동형 자사몰, 포인트 충전형 모델 등을 단계별로 설계하고 구현 연습까지 이어가기 위한 작업대입니다.

## 초기 메뉴

- 시작하기
- 비즈니스 정의
- 요구사항 설계
- 도메인 설계
- 데이터 설계
- 시스템 아키텍처
- 로드맵

전체 구현 로드맵은 앱 내부에서 상품, 회원, 장바구니, 주문, 결제, 재고, 배송, 취소/환불, 프로모션, 관리자, 외부 연동, 테스트, 배포, 고도화, 완성 프로젝트 순서로 관리합니다.

## 개발

```bash
npm install
npm run dev
```
